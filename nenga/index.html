年賀状リスト管理

🎍 年賀状は、相手の最新の住所と肩書きが向こうから届く日です。
受け取ったその場で記録しておかないと、1年後にまた去年のまま出すことになります。
喪中の方を外すのも、翌年にちゃんと戻すのも、仕組みでやります。

🔒 入力した情報はこの端末のブラウザの中にだけ保存されます。どこにも送信されません。
住所録は個人情報のかたまりです。共用のパソコンでお使いの場合はご注意ください。バックアップの書き出しもご用意しています。

いまの住所録を取り込む

Excelやスプレッドシートの住所録を、見出しの行ごとそのままコピーして下に貼り付けてください。タブ区切り・カンマ区切りのどちらでも読み取ります。
見出しは「氏名 / 名前 / お名前」「会社 / 会社名」「部署」「役職 / 肩書」「郵便番号 / 〒」「住所 / 住所1」「住所2 / 建物」「敬称」「差出人 / 名義」「メモ / 備考」を見ています。

書き出す

⚠️ 書き出したファイルには、氏名と住所がそのまま入ります。共有フォルダやデスクトップに置いたままにしないでください。年賀状ソフトに取り込んだら消すのが安全です。

CSVには「出す」の方だけが入ります。喪中・出さないの方は必ず外れます。書き出す前に内訳をお見せします。
