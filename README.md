# 秘書ノート (Hisho Notes)

> 役員秘書・経営者・士業のための業務ツール集

業務で「これ毎週やってる…自動化できるはず」と思った作業をツール化して順次公開していくシリーズです。秘書業務の **効率化と脱属人化** を目的に、ブラウザだけで動く軽量ツールを揃えていきます。

## 公開中のツール

| # | ツール | 概要 | 場所 |
|---|---|---|---|
| 1 | **会食お店ピックアップ** | エリア・条件から★4.0以上(食べログ★3.5相当)の会食店を絞り込み。食べログ検索・カレンダー登録・前日リマインド文生成までワンクリック | [restaurant/](restaurant/) |
| 2 | **訪問先カルテ** | 商談前・訪問前の会社/人物リサーチを1画面に集約。7項目チェックリスト+印刷ブリーフィングシート+履歴蓄積。API不要・登録不要 | [visit-prep/](visit-prep/) |
| 3 | **会議パック** | 確定済みの会議を1入力でカレンダー登録URL・ICSファイル・案内文(3形式)に一括展開。テンプレ保存・履歴・データ移行対応。API不要・登録不要 | [meeting-pack/](meeting-pack/) |
| 4 | **VIPプロファイル管理** ★旗艦 | 役員・取引先・重要顧客の好み/NG/記念日/贈答履歴/関係性を構造化。アレルギー強調表示・記念日リマインド・JSONエクスポートで引き継ぎ可能。秘書の頭の中を組織に残す | [vip-profile/](vip-profile/) |

## 番外編(売り物ではないが、作ってみた系)

本編とは別軸で、生活の中の「業務化された理不尽」を解消する小さなツールを置く場所です。問い合わせサポートは行っていません(GitHub Issues歓迎)。

| ツール | 背景 | 場所 |
|---|---|---|
| **スポ少サポートツール** | 娘のミニバスで気づいた運営作業。校外試合の配車・練習当番の月間ローテ・自校試合の役割分担・月謝のデポジット管理を、場面別4タブで LINE貼り付け用テキストに | [spo-tool/](spo-tool/) |

## 開発予定

| 仮称 | 概要 |
|---|---|
| 議事録テンプレ整形 | OpenAI BYOK、テキスト整形・話者ラベル付け |
| 年賀状リスト管理 | CSV取り込み、住所正規化、印刷用宛名出力 |

## 設計思想

- **シングルHTML / サーバ不要**:全ツールがブラウザ単体で完結。ローカル保存(localStorage)中心
- **API利用は最小限**:無料の公的API優先。BYOK(自分のキー)時は事故防御を多層化
- **業務に持ち込みやすい**:カスタマイズはコード直書き換えで完結、シングルファイルなので渡しやすい
