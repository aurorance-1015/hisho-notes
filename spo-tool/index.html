スポ少サポートツール

スポ少の運営作業を、ボタン一発で LINEに貼り付けできるテキストに。
🏀 娘のミニバスで気づいた運営作業を、ツールにしてみました。
売り物ではなく 「作ってみた」 系です。問い合わせサポートは行っていません(Issueは歓迎)。
他校での試合・遠征など、車で移動する日。集合案内 + 配車割(引率)を作成します。
姓が車のドライバー姓と一致する子は、その家の車に優先で乗ります。
乗車数は子どもの数(ドライバー自身は含めない)。例:4席=子4人まで。

📋 LINEに貼り付け用テキスト

生成結果はこのブラウザ内のみ。サーバには一切送信していません。入力内容は localStorage に保存されます。
期間と曜日を指定すると、練習日の当番を1ヶ月分まとめて公平ローテ。お休みは除外、試合の日は予告として表示します。月初に配る「今月の予定表」向け。
〜
お盆・祝日など練習がない日。当番表から除外されます。
試合日は当番を割り振らず「🏀 ○○カップ ※出欠・詳細は別途」と予告表示します。役割分担は「イベント当番」で作成してください。

📋 LINEに貼り付け用テキスト

担当回数(今シーズン累計・公平性チェック)

「履歴に記録」を押すと、この割り振りの回数がシーズン累計に加算され、次回の当番表作成時に自動で反映されます(回数が少ない人が優先されます)。
生成結果・累計はこのブラウザ内のみ(localStorage)。サーバには一切送信していません。
自分の学校での試合・大会など、多くの保護者が集まって会場設営する日。開催案内 + 役割分担を作成。希望を考慮し、会場に留まる「常駐」役割は常駐NGの人を避けます。
「常駐」= 会場に留まる必要がある役割(その役を希望しない人を優先的に外します)。
書かない人は「なんでもOK」扱い。「名前:常駐NG」と書くと常駐役割を避けます。

📋 LINEに貼り付け用テキスト

イベント役割の担当回数(累計)

イベント当番も「履歴に記録」で累計が残り、次回は担当回数の少ない人が優先されます(希望が最優先)。
生成結果・累計はこのブラウザ内のみ(localStorage)。サーバには一切送信していません。
