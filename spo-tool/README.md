# 秘書ノート 番外編 / スポ少 配車割ジェネレータ

> 「秘書ノート」(役員秘書・経営者・士業のための業務ツール集)の **番外編**。
> スポ少代表の毎週末をちょっとだけラクにする、小さなツール。

---

## これ何?

娘のミニバスで気づいたことがあります。

**スポ少の代表って、時間がある人がやる**。でも本当は、時間がない人ほどツールが必要。仕組み化する暇があれば最初から仕組み化してる。だから手作業がずっと残る。

そこに「ボタン一発で配車割が出てくる」だけのツールを置いてみました。これだけです。売り物ではなく、作ってみた系です(笑)

## できること

- **配車割を 1ボタンで生成** ─ 参加する子と、車を出せる家(席数)を入力するだけ
- **姓マッチング** ─ ドライバーの姓と一致する子は、その家の車に優先で乗る(田中さんちの太郎くんは田中車へ)
- **LINEに貼り付け可能なテキストで出力** ─ 集合日時・場所込みの整形済みテキスト、コピーボタン1つで取れる
- **入力内容の自動保存** ─ 次回起動時に前回のメンバー・車登録が復元(「先週とほぼ同じ」が一瞬で)
- **席不足アラート** ─ 漏れた子の名前を警告、車の追加や調整がすぐ分かる

---

## 使い方

1. `index.html` をブラウザで開く(ダブルクリックでOK、サーバ不要)
2. 集合日時・場所を入力
3. 参加する子の名前を 1行 1人 で入力
4. 車を出せる家と席数を入力
5. **「🚗 配車を生成」** をクリック
6. 出力テキストを **「コピーする」** で取得 → LINEに貼り付け

入力10秒、生成1秒、コピー1秒。LINE貼り付けまで合計 **12秒**で完了します。

---

## プライバシー・データの扱い

- 本ツールは **完全にブラウザ内で動作**(サーバ通信ゼロ)
- 入力内容(子の名前・ドライバー・席数など)は **localStorage** に保存(あなたのブラウザにだけ)
- 名前を含む全データは外部に送信しません
- APIキー不要、ログイン不要、課金なし
