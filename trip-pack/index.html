出張リンクパック

役員秘書・経営者・士業のための業務ツール集
🧳 出張の手配で、同じ「行き先と日付」を、乗換サイト・新幹線の予約・ホテル検索…と何度も打ち直していませんか。
1回の入力で、乗換・予約・ホテル・地図のリンクと、役員に送る行程表、出張準備のチェックリストをまとめて作ります。
🔒 API不要・登録不要。入力内容はこのブラウザの中にだけ保存されます。

出張の内容

駅名は「東京」「新大阪」のように、「駅」を付けずに入れるのが確実です。
行き
帰り
行きと帰りが同じ日なら「日帰り」として、ホテルの検索を省きます。
⚠️ 予約する前に、リンク先の画面で「日付・時刻・人数」を必ず確認してください。
リンク先サイトの仕様が変わると、条件がうまく引き継がれないことがあります。日付違いの予約は取り消し料がかかる場合があるので、最後は必ずご自身の目で。

検索・予約リンク

行程表をつくる

予約が決まったら、便名・時刻・ホテル名を入れてください。役員や同行者に送る文面ができます。空欄の項目は省かれます。
送る前に、便名・時刻・ホテル名に誤りがないか確認してください。文面はこの場で直せます。

出張準備チェックリスト

項目は自由に追加・削除できます。「田中社長は新幹線は窓側E席」「○○社は受付で入館証が必要」のような、自分だけが知っている段取りを書き足していくと、そのまま引き継ぎ資料になります。
✓ 0 / 0 完了
複数行のテキストを貼り付けると、1行ずつまとめて追加されます(後任から受け取ったリストの取り込みに)。
リストとチェック状態はこのブラウザに保存されます。次の出張の前に「チェックを外す」を押してください(項目は残ります)。

🔒 データの扱い
・このツールはリンクを作るだけです。予約や支払いはしません。予約・支払いは、リンク先の各サイトでご自身で行ってください。
・入力した内容(出張先・日程・行程など)は、お使いのブラウザ(localStorage)にのみ保存され、どこにも送信されません。
・共有PCでは、出張の予定が次の人に見えてしまいます。使い終わったら履歴を削除するか、ブラウザのプライベートモードでご利用ください。
